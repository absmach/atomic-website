Browse the source

Open the app’s Dashboard and select Browse source under Code. The source is read-only and comes from a verified version, marked Verified source.

  • Choose a version from the menu at the top. The default policy keeps the newest 20 verified versions plus versions needed by retained deployments. Your installation’s retention setting can differ.
  • Use Find a file to search the file tree.
  • Copy or Download the open file.

Download everything

Download source downloads the selected version’s files as an archive. Apps are written in React with TypeScript and styled with Tailwind CSS. The archive leaves out build output, installed packages, Atomic’s own working files and files excluded by its path and filename filters, including common credential files. These filters do not scan every file’s contents for secrets: review the archive before sharing it.

While a build is running you can read the files it has saved so far, but only verified versions can be downloaded.

The proposed launch plans include source browsing on every plan and downloads on Builder and Pro. Early-access availability can differ from those proposed limits; the current source download does not establish a paid subscription.

What the source is not

The source describes the app. It is not a backup of a running app: it does not include the app’s users, records, uploaded files or hosting. Generated projects can include packages under third-party licenses; check them before you redistribute the project. See what you can take with you.
